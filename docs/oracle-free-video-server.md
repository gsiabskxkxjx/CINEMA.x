# خادم فيديو مجاني على Oracle Cloud (حتى 200 GB)

دليل لتشغيل خادم ملفات صغير يخدم أفلامك بـ HTTPS، ثم لصق روابطها في التطبيق بخيار **«من رابط»**.
نفس الخطوات تعمل على أي VPS أو جهاز Ubuntu آخر.

> ارفع فقط ما تملك حقوقه أو مرخّصاً لك.

## اقرأ هذا قبل أن تبدأ (حدود حقيقية)

| الموضوع | الواقع |
|---|---|
| **المساحة** | 200 GB فقط (قرص واحد يشمل نظام التشغيل)، أي نحو 80–90 فيلماً بحجم 2 GB. **ليست 500 GB**. |
| **البطاقة** | التسجيل يتطلب بطاقة ائتمان (أو خصم تعمل كائتمان). **لا تُقبل** بطاقات PIN أو الافتراضية أو المسبقة الدفع أو ذات الاستخدام الواحد. قد تظهر عملية «حجز» مؤقت على البطاقة ولا يُخصم منها. |
| **السرعة** | الشكل AMD Micro: 1 GB ذاكرة وحتى **50 Mbps** فقط، يكفي لعدد قليل من المشاهدين معاً. الشكل Ampere A1 أقوى لكن السعة قد تكون غير متوفرة في منطقتك. |
| **البث** | حتى 10 TB شهرياً مجاناً. |
| **خطر الاسترجاع** | قد تسترجع Oracle السيرفرات «الخاملة»: إذا خلال 7 أيام كان استخدام المعالج (95th percentile) أقل من 20% **و** الشبكة أقل من 20% (و الذاكرة أقل من 20% لشكل A1). خادم ملفات قليل المشاهدة قد يقع تحت هذا الشرط. **لا تجعل هذا الخادم النسخة الوحيدة من أفلامك**؛ احتفظ بالأصل عندك. |
| **الحساب الخامل** | الحساب غير المستخدم 30 يوماً أو أكثر قد يُعدّ مهجوراً ويُعلَّق أو يُحذف. |

المصادر: [Always Free Resources](https://docs.oracle.com/iaas/Content/FreeTier/resourceref.htm) و[Free Tier FAQ](https://www.oracle.com/in/cloud/free/faq/). الشروط تتغير، فراجعها قبل التسجيل.

## الخطوات

### 1) حساب Oracle
- سجّل من <https://cloud.oracle.com/free>.
- اختر **Home Region** بعناية: لا يمكن تغييرها لاحقاً، والموارد المجانية يجب أن تُنشأ فيها.

### 2) إنشاء الخادم (VM)
من لوحة Oracle: **Compute ← Instances ← Create instance** (قد تختلف التسميات قليلاً):
1. **Image:** Ubuntu 22.04 أو 24.04.
2. **Shape:** `VM.Standard.E2.1.Micro` (AMD) أو `VM.Standard.A1.Flex` (Ampere) بحدود المجاني فقط (علامة *Always Free-eligible*).
3. **Boot volume:** فعّل *Specify a custom boot volume size* واجعله **200 GB** (يستهلك كل حصتك المجانية من التخزين، لذلك خادم واحد فقط بهذا الحجم).
4. **Networking:** اترك *Assign a public IPv4 address* مفعّلاً.
5. **SSH keys:** اختر *Generate a key pair* ونزّل المفتاح الخاص (`.key`) واحتفظ به. من يملكه يدخل خادمك.
6. أنشئ الخادم ودوّن **Public IP**.

### 3) فتح المنفذين 80 و443 عند Oracle
**Networking ← Virtual cloud networks ← (شبكتك) ← Subnet ← Security List ← Add Ingress Rules**، أضف قاعدتين:
Source CIDR `0.0.0.0/0`، Protocol `TCP`، Destination Port `80`، ثم نفسها للمنفذ `443`.
(السكربت يفتح المنفذين داخل الخادم نفسه أيضاً؛ كلا الجدارين لازم.)

### 4) نطاق مجاني
HTTPS يحتاج اسماً. أسهل طريقة مجانية: [DuckDNS](https://www.duckdns.org): أنشئ نطاقاً فرعياً مثل `mycinema.duckdns.org` واجعل عنوانه **Public IP** الخادم. (أو أي نطاق تملكه بسجل A.)

### 5) تجهيز الخادم بأمر واحد
```bash
ssh -i oracle.key ubuntu@<Public-IP>
curl -fsSL https://raw.githubusercontent.com/gsiabskxkxjx/CINEMA.x/main/tool/oracle/setup-server.sh -o setup-server.sh
less setup-server.sh            # اقرأه قبل التشغيل (q للخروج)
sudo bash setup-server.sh mycinema.duckdns.org
```
السكربت يثبّت Caddy (يجلب شهادة HTTPS مجانية تلقائياً)، وينشئ `/srv/videos`، ولا يخدم إلا ملفات الفيديو والترجمة، بلا قائمة ملفات، مع دعم التقديم والترجيع (Range).

اختبر: `echo test | sudo tee /srv/videos/t.mp4` ثم افتح `https://mycinema.duckdns.org/t.mp4` يجب أن يُحمَّل.
إن لم تصدر الشهادة: `sudo journalctl -u caddy -f` (غالباً سجل A خاطئ أو المنفذ 80 مغلق).

### 6) رفع الأفلام من الكمبيوتر
أضف الخادم إلى `~/.ssh/config`:
```
Host cinema-vm
  HostName <Public-IP>
  User ubuntu
  IdentityFile ~/oracle.key
```
ثم:
```bash
bash tool/oracle/upload-video.sh film.mp4 cinema-vm mycinema.duckdns.org
```
يرفع الملف باسم عشوائي ويطبع الرابط. إن انقطع الاتصال أعد الأمر نفسه فيكمل من حيث وقف (يحفظ الاسم بجوار الملف الأصلي). على ويندوز استخدم WSL أو **WinSCP** (يدعم الاستئناف) وارفع إلى `/srv/videos`.
من الهاتف: أي تطبيق مدير ملفات يدعم SFTP يعمل أيضاً، لكن الكمبيوتر أنسب للملفات الكبيرة.

### 7) ربطه بالتطبيق
لوحة الإدارة ← الفيلم ← روابط الفيديو ← **+** ← **من رابط**، الصق `https://mycinema.duckdns.org/<الاسم>.mp4` وسمِّ الجودة (1080p مثلاً).

## نصائح
- **بدء أسرع للتشغيل:** ضع بيانات MP4 في بداية الملف: `ffmpeg -i in.mp4 -c copy -movflags +faststart out.mp4`. ملفات MKV تعمل في المشغّل كما هي.
- **المساحة:** `df -h /` على الخادم. احذف فيلماً بـ `sudo rm /srv/videos/<الاسم>` بعد حذف مصدره من اللوحة.
- **الأمان:** أسماء الملفات عشوائية ولا توجد قائمة ملفات، لكن من يملك الرابط يشاهد الملف مباشرة، فقيد Premium لا يحمي الملف إذا تسرّب رابطه.
- **المفتاح الخاص:** لا تضعه في أي مستودع ولا ترسله لأحد.
- **السعة:** إن لم تكفِ 200 GB، فـ Backblaze B2 بنحو 3.4 دولار شهرياً لـ 500 GB (انظر قسم 5-ج في README).
